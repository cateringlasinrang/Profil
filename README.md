# Savory Delights Catering - Modern Website Template

A clean, responsive, and interactive website template for a catering business built with HTML5, CSS3, and modern JavaScript.

## Features

- **Responsive Design**: Mobile-first grid and flexbox layout that adapts to all screen sizes.
- **Interactive Menu Filter**: Easily switch between Starters, Mains, Desserts, and Beverages.
- **Live Price Calculator**: Real-time pricing estimation based on guest count, package type, and add-ons.
- **Event Booking Form**: Built-in inquiry form with guest count selection and special request fields.
- **Service Highlights**: Styled sections for Weddings, Corporate Events, and Private Dinners.
- **Customer Testimonials**: Visual cards featuring feedback and star ratings.

## Getting Started

### Option 1: View Locally
1. Download or clone this repository.
2. Open `index.html` in your favorite web browser.

### Option 2: Deploy to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Source**, select `main` (or `master`) branch and root `/`.
4. Click **Save**. Your website will be live in a few minutes!

## File Structure

## Customization

- **Colors**: Modify CSS variables in `:root` inside `index.html` (e.g., `--primary-color`, `--accent-color`).
- **Menu & Pricing**: Update the dishes, packages, and pricing values directly inside the HTML structure.
